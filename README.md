# STARBEAM — peaceindex.online

Статический сайт для GitHub Pages на трёх языках: русский (корень, язык определяется по браузеру), `/en/` и `/es/`. Сервер не нужен. Бортовой журнал первых пилотов хранится в Supabase (бесплатный тариф).

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | сайт (русский; переключатель RU/EN/ES, автоопределение языка) |
| `en/index.html`, `es/index.html` | те же страницы с английскими и испанскими заголовками и превью |
| `config.js` | ключи бортового журнала — **единственный файл, который нужно редактировать** |
| `og.png`, `og-en.png`, `og-es.png` | превью ссылки на трёх языках |
| `favicon.svg` | иконка вкладки |
| `sky-4k.webp`, `sky-8k.webp`, `sky-4k.jpg` | карта неба: 112 тыс. звёзд каталога Hipparcos + Млечный Путь (своя, без внешних сервисов) |
| `tex/` | текстуры Земли и Луны (NASA Blue Marble / Earth at Night) в WebP |
| `CNAME` | привязка домена `peaceindex.online` — не удалять |
| `.nojekyll` | GitHub Pages отдаёт файлы как есть |
| `supabase/schema.sql` | таблица пилотов и функции регистрации |

## 1. Бортовой журнал (Supabase), 10 минут

1. Зайти на supabase.com → New project (регион поближе, например São Paulo). Пароль базы сохранить.
2. SQL Editor → New query → вставить весь `supabase/schema.sql` → Run.
3. Project Settings → API: скопировать **Project URL** и **anon public** key.
4. Открыть `config.js` и вписать:
   ```js
   SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJ...',
   ```
   Это действует сразу на все три языковые версии.
   anon-ключ публичный по замыслу Supabase: таблица закрыта, сайт может только вызвать регистрацию и получить счётчики. Контакты и кошельки наружу не отдаются. **service_role ключ в сайт не вставлять никогда.**

Пока поля пустые, сайт работает, но кнопка регистрации показывает «Бортовой журнал скоро откроется».

## 2. Выкладка на GitHub Pages

В репозитории, к которому привязан peaceindex.online:

1. Старую карту «Ночи провинций» перенести в папку `casas/` (чтобы старые ссылки жили): `casas/index.html`, `casas/es.html`.
2. Загрузить в корень всё содержимое этой папки вместе с папками `en/` и `es/` (Add file → Upload files, перетащить всё сразу). Папку `supabase/` можно не загружать.
3. Проверить, что `CNAME` содержит `peaceindex.online`, а в Settings → Pages включено **Enforce HTTPS**.
4. Через 1–2 минуты открыть сайт с Ctrl+Shift+R.

Через git:
```
mkdir casas
git mv index.html casas/index.html
git mv es.html casas/es.html
# скопировать сюда всё содержимое архива (index.html, en/, es/, config.js, og*.png, favicon.svg, .nojekyll, CNAME)
git add -A && git commit -m "STARBEAM" && git push
```

## 3. Проверка после выкладки

- Земля, небо, телескоп, APOD и экзопланеты загрузились.
- Регистрация: записаться тестовым email → появился номер и личная ссылка. В Supabase → Table Editor → `pilots` появилась строка.
- Открыть свою ссылку `?ref=…` в другом браузере, зарегистрировать второго пилота → у первого «По твоей ссылке уже 1 пилот».
- Скачать Galactic ID → PNG открывается, QR ведёт на сайт по ссылке.
- Языки: открыть `/`, `/en/`, `/es/`; переключатель RU/EN/ES справа вверху.
- Превью: кинуть себе в Telegram три ссылки — `peaceindex.online`, `/en/`, `/es/`. Если превью старое — @WebpageBot в Telegram сбрасывает кэш.
- Тестовые записи потом удалить в Table Editor.

## Выгрузка пилотов (для будущего аирдропа)

Supabase → SQL Editor:
```sql
select serial, callsign, contact, wallet, referred_by,
       (select count(*) from pilots r where r.referred_by = p.ref_code) as invited, created_at
from pilots p order by serial;
```
Кнопка Download CSV под результатом.

## Ключи и лимиты

- NASA API (APOD): 1000 запросов в час на ключ на всех посетителей; ответы кэшируются в браузере. Если превысим — блок APOD покажет ссылку на архив, остальное работает.
- Supabase free: 500 МБ базы и 50 000 активных пользователей в месяц — для журнала с запасом.

## Языки

- Корень `peaceindex.online` открывается на языке браузера (русский, испанский, иначе английский); выбор через переключатель запоминается.
- `peaceindex.online/en/` и `/es/` всегда открываются на своём языке — их удобно раздавать англо- и испаноязычным друзьям, превью тоже будет на их языке.
- Личная ссылка пилота ведёт на версию того языка, на котором он регистрировался.
